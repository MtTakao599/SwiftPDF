SwiftPDF portable mode

While this file sits next to SwiftPDF.exe, SwiftPDF keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the Data folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder, including Data, to move SwiftPDF with its settings.

Delete this file to use the normal per-user folder (%LOCALAPPDATA%\SwiftPDF) instead. If Data
can't be written (for example on a read-only drive), SwiftPDF says so and uses the per-user folder instead.
